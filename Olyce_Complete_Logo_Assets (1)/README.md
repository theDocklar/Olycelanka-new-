# Olyce logo assets

Designed for olycelanka.com, whose website currently brands itself as **Olyce**. The package also includes **Olycelanka.com** wordmarks.

- `svg/`: scalable editable vector logos, transparent background.
- `png/`: large transparent logo renders.
- `favicons/`: icon PNG sizes, favicon.ico, Apple and Android icons, and web manifest.

## HTML setup
Copy favicon files to your site's `/public` folder, then add:
```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/icon-32.png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
```

Palette: deep teal `#173A36`, island green `#246B5A`, warm gold `#D6A95C`.

This is a newly created simplified identity concept, not a vectorization of the earlier illustrated concept.
